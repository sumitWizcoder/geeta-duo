# GitaQuest

Learn the Bhagavad Geeta in a Duolingo-style, bite-sized, gamified web app.

Stack: Vite, React 19, TypeScript, Tailwind, Zustand (localStorage persistence), framer-motion.

## Scripts
- `npm run dev` start the dev server
- `npm run build` type-check and build
- `npm run lint` lint
- `npm test` run unit tests

## Content
- `src/data/chapters.json` chapter titles, colours, icons
- `src/data/lessons.json` lessons (concept, explore cards, questions, shloka)
